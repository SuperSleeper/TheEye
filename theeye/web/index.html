      Cameras

      Pick your camera brand and enter its address and login — stream URLs are built for you. Use Custom URL for anything else (RTSP, RTMP, HTTP-FLV/MJPEG, UDP/SRT, files). Test each stream before saving.

      Saved logins

      Store a username and password once and pick it on any camera. Changing a saved login updates every camera that uses it. Passwords are kept in the config file (readable only by you) and never sent back to the browser.

      Objects to detect

      Delivery & emergency services

      Tags Amazon, UPS, FedEx and USPS vehicles (logo, colours, shape) using the visual-search model already running, and the recordings they're in, so you can search “ups today” or “mail truck”. Uniformed drivers are only tagged from a large, clear view: at normal camera distances a uniform is too small to tell. Police cars, fire trucks and ambulances (and their crews) are tagged too, with a stricter 98% bar.

      Animal types

      The detector only knows bird, cat and dog, so a squirrel can come out as “bird”. Each animal gets a closer look using the visual-search model already running (no extra load); a confident answer is added to its tags and is searchable (“squirrel today”, “pomeranian”). Needs visual search embeddings on. Shorter lists give sharper answers: list the animals and breeds you actually get.

      Smart search (local LLM)

      Small models (3–8B) leave GPU memory for detection. The interpreted filter is always shown with search results.
